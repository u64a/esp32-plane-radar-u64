# Security policy

## Supported versions

Security fixes are made on the `main` branch. Only firmware produced by the
current certified release workflow or an explicitly supported GitHub Release
should be treated as supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/u64a/esp32-plane-radar-u64/security/advisories/new)
so details and proof-of-concept material remain private until a fix is ready.

Please include the affected commit or release, hardware variant, impact,
reproduction steps, and any relevant serial output or packet capture with
credentials and precise location data removed.

Reports will be acknowledged as soon as practical. Confirmed issues will be
tracked privately while a fix and replacement firmware are prepared, then
disclosed with appropriate credit unless the reporter requests otherwise.
